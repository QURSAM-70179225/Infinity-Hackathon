## Rules
- Work only in your own folder to avoid merge conflicts.
- Commit small and often: `git add .` → `git commit -m "what changed"` → `git pull` → `git push`.
- Pull before you push.
- Never commit `.env`.
- Tell the team before changing an API route or its JSON shape.
- Stop adding features at 2h15. After that: test, fix, record the demo.
